# Discover Official Catalog membership from published releases

The Official Catalog discovers every Published Design System from its release directory and validated publication metadata. Generated metadata drives catalog discovery, Design System Previews, current and exact Design Contract routes, and acceptance coverage. Adding a valid identity requires no application registry, identity union, preview branch, fixed count copy, or repeated route fixture.

Every discovered release must pass publication validation before generation. Invalid metadata, missing evidence, failed review state, digest mismatch, duplicate identity, unsupported preview values, and unexpected release files block the complete generation step.

This decision supersedes only the fixed membership statement in ADR 0012. The Official Catalog remains public, stateless, first party, and MIT licensed. Foundation, Editorial, Mono, and Command remain Published Design Systems with the same public routes and immutable Design Contract bytes.
