# Publish a public, stateless Official Catalog under MIT

AgentKogei publishes Foundation, Editorial, Mono, and Command as four complete Design Systems in a public Official Catalog. The MIT License covers all repository source code and Design System content. Each current or exact Design System Release can be inspected and retrieved without an account or authorization.

The web application keeps no persistent application state. The CLI sends only the Design Contract request initiated by the Builder and the installed Design Contract works offline. AgentKogei accepts that anyone may use, modify, distribute, sublicense, or sell copies of the catalog content in exchange for a simple product with no identity barrier or protected delivery path.

Historical vendor resources are operational state outside the repository. Their cleanup is owner managed and does not change this implementation.
