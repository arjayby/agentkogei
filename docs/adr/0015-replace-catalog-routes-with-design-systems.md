# Replace Catalog routes with Design Systems routes

AgentKogei presents its public collection at `/design-systems` and each Design System Preview at `/design-systems/[slug]`. The former `/catalog` routes are removed without redirects because consistent Design System language is preferred over compatibility with old bookmarks and published links. This supersedes ADR 0014 only where it preserves the former public routes; discovery, validation, public access, stateless delivery, first party ownership, and MIT licensing remain unchanged.
