# Use two part Design System Release versions

Design System Releases use `major.minor` identifiers. Minor releases add compatible direction and major releases may introduce breaking visual or behavioral direction; there is no patch release category. Before launch, Foundation, Editorial, Mono, and Command are reset to a single `1.0` release and Foundation's earlier release history is removed. This simpler public model applies only to Design System Releases, while software packages retain conventional three part versions.
